# Requests for Comments (RFCs)

RFCs documentam **decisões técnicas relevantes** — propostas colocadas em
discussão antes de virarem definitivas, com motivação, alternativas avaliadas e
riscos. Uma vez aceitas, alimentam os [ADRs](../adr/README.md) correspondentes.

| RFC | Título | Status |
|---|---|---|
| [RFC-001](RFC-001-escolha-nuvem.md) | Escolha do provedor de nuvem | Aceita |
| [RFC-002](RFC-002-banco-de-dados.md) | Escolha do banco de dados gerenciado | Aceita |
| [RFC-003](RFC-003-autenticacao-cpf.md) | Estratégia de autenticação por CPF (serverless) | Aceita |
| [RFC-004](RFC-004-observabilidade.md) | Estratégia de observabilidade | Aceita |

## Convenção de status

`Rascunho` → `Em revisão` → (`Aceita` | `Rejeitada`) → `Substituída por RFC-XXX`
